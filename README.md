# EduGenine AI

**가천대학교 2024-2학기 「AI 중심세상」 과목 팀프로젝트**

An AI learning companion for personalized practice, explanations, and feedback, with a discrete mathematics demo.

수업 팀프로젝트에서 본인이 작성한 코드를 정리한 **개인 저장소**입니다. 팀 전체 결과물의 공식 저장소가 아니며, 팀 발표 자료와 다른 팀원의 작업물은 포함하지 않습니다.

여러 과목에서 학습자의 목표와 수준에 맞는 문제, 해설, 피드백을 제공하는 학습 도우미를 지향합니다. 현재 실행 가능한 예제는 **이산수학 10문항**이며, 기본 모드는 문제은행으로 동작합니다. GPT-2와 LSTM은 별도의 선택 실험으로 구성했습니다.

## 주요 기능

- 문제·정답·해설·피드백 제공
- 주제 선택과 풀이 결과에 따른 목표 난이도 조정
- 오답 주제 우선 출제와 연속 오답 안내
- 숫자·분수·집합·경로 및 등록된 텍스트 답안 채점
- 세션별 복습 목록과 JSON·한국어 HTML 학습지 저장
- 선택 실험: 로컬 GPT-2 파인튜닝·문제 초안 생성, 실제 풀이 이력을 이용한 LSTM 학습

## 실행 방법

Python 3.10 이상과 이미 준비된 Jupyter 또는 VS Code 노트북 환경을 사용합니다. 기본 풀이 기능은 Python 표준 라이브러리만 필요합니다.

1. 저장소를 내려받아 프로젝트 폴더를 엽니다.
2. [EduGenine_AI.ipynb](EduGenine_AI.ipynb)를 열고 Python 커널을 선택합니다.
3. 위에서부터 셀을 실행합니다. 기본 설정은 입력 대기나 파일 저장 없이 합성 데모를 실행합니다.
4. 직접 문제를 풀려면 설정 셀의 `INTERACTIVE = True`로 바꿉니다. 기록을 저장하려면 `SAVE_REPORT = True`도 설정합니다.

학습지는 `outputs/`에 저장됩니다. HTML을 브라우저에서 열어 인쇄 기능의 **PDF로 저장**을 이용할 수 있습니다. 3분 제한 시간은 답안 제출 후 판정하며, 입력 대기를 강제로 종료하지 않습니다.

프로젝트 폴더에서 다음 명령으로 테스트할 수 있습니다.

```bash
python -m unittest discover -s tests -v
```


## 데이터와 구현 범위

[data/discrete_math.json](data/discrete_math.json)에는 이산수학 예제 10문항의 문제·정답·해설·피드백이 들어 있습니다. 기본 실행에 필요하므로 저장소에 함께 포함합니다. KorQuAD나 대규모 학습 데이터는 포함하지 않습니다.

| 구분 | 현재 범위 |
| --- | --- |
| 기본 학습 | 문제은행 선택과 규칙 기반 난이도 조정. 생성형 AI를 사용하지 않습니다. |
| 채점 | 지정된 정답과 비교합니다. 자유서술형 의미 채점과 부분점수는 지원하지 않습니다. |
| GPT-2 | 검토된 로컬 모델에서 실행하는 실험 코드입니다. 생성 결과는 사람의 검토가 필요한 초안입니다. |
| LSTM | 실제 시간순 풀이 이력으로 다음 정답 여부를 예측하는 실험입니다. 기본 난이도 정책과 연결하지 않습니다. |

다른 과목으로 확장하려면 해당 과목의 문제·정답·해설을 준비하고, 답안 형식에 맞는 채점과 주제 분류를 적용해야 합니다. 현재 생성 프롬프트와 주제 키워드는 이산수학 예제에 맞춰져 있습니다.

## 검증과 선택 실험

기본 노트북 순차 실행과 테스트 **22개**를 통과했습니다. 노트북은 실행 출력과 실행 횟수를 비운 상태로 제공합니다. 실제 GPT-2/LSTM 학습·생성, GPU 경로, PDF 텍스트 추출은 실행 검증하지 않았습니다. 자세한 내용은 [구현 안내](docs/IMPLEMENTATION.md)와 [검증 기록](docs/VALIDATION.md)에 있습니다.

선택 실험은 사용할 패키지·의존성·모델을 검토한 로컬 환경에서 명시적으로 켜야 합니다. 자동 설치나 모델 다운로드 코드는 없습니다. 검토를 마친 정확한 버전만 사용하며, 실행 플래그를 켜는 것으로 검토를 대신할 수 없습니다.

10문항과 합성 데모는 모델 성능이나 실제 학습 효과를 입증하지 않습니다. 난이도는 데모용 수동 분류이며, 생성 문제의 정답 검토와 실제 학습자별 평가가 필요합니다.

개인 풀이 기록, 입력 학습 자료, 모델 가중치, 환경 설정과 캐시는 `.gitignore`로 제외합니다.
