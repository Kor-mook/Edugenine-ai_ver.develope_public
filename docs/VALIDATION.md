# 검증 결과

검증일: 2026-11-18

- `python -X utf8 -m unittest discover -s tests -v`: **22개 테스트 통과**
- 기본 설정의 노트북 전체 코드 셀을 순서대로 실행했다. 공개본에서는 실행 출력과 실행 횟수를 비웠다.
- 기본 실행 중 torch, transformers, PyPDF2, numpy, keras, datasets, fpdf를 import하지 않는 것도 테스트했다.
- 10문항의 정답과 별칭, 집합/분수 동등성, 그래프 최단 경로, 데이터 중복, 세션 분리, 재출제 방지, 연속 오답, 시간 초과, 난이도 범위, 종료/재개를 검증했다.
- 임시 폴더에서 기록 JSON과 한국어 HTML 저장, HTML 입력 이스케이프, 기존 결과를 덮어쓰지 않는 동작을 확인했다.
- 실제 모델 없이 학습/검증 분리, 프롬프트의 주제·난이도 반영, 응답 손실 마스킹과 길이 초과 검사를 테스트했다. 이 검사는 신경망 실행 검증을 대체하지 않는다.

노트북의 기본 실행에서 나오는 5문제, 3정답 데모는 미리 정한 입력으로 실행하는 **합성 예시**다. 사용자 성적이나 AI 모델 성능 결과가 아니다.

실제 GPT-2/LSTM 학습·생성, GPU 동작, PyPDF2 텍스트 추출, 노트북 GUI, 브라우저의 PDF 인쇄는 실행 검증하지 않았다. 검토되지 않은 외부 패키지나 모델을 실행하지 않기 위해 선택 경로는 꺼 둔 상태다.
