# 구현 및 실험 안내

## 기본 학습 흐름

`edugenine.py`는 Python 표준 라이브러리만 사용합니다. 문제 데이터를 읽고, 출제·채점·피드백·기록 저장을 세션별로 관리합니다. 주제에 맞는 미풀이 문제 중 최근 오답 주제와 목표 난이도를 고려해 다음 문제를 고릅니다. 한 세션에서 같은 문제를 반복 출제하지 않습니다.

난이도는 1~5 범위의 데모용 수동 분류입니다. 정답이면 목표 난이도가 1단계 올라가고, 오답이나 시간 초과이면 1단계 내려갑니다. 해당 단계 문제가 없으면 가까운 난이도를 선택하므로 목표와 실제 문제 난이도가 다를 수 있습니다. 현재 데이터에는 1~3단계 문제가 있습니다.

숫자는 소수와 분수를 정확히 비교하고 집합은 원소 순서를 무시합니다. 경로는 정점 순서를 유지합니다. 텍스트 답안은 등록된 정답 또는 별칭과 일치해야 합니다. 자유서술형 의미 채점이나 부분점수는 지원하지 않습니다. 사용자 답안을 코드로 실행하지 않습니다.

입력 대기를 강제로 종료하지 않고 제출 시 소요 시간을 계산해 시간 초과를 판정합니다. 최근 3회 제출이 모두 오답이면 복습 안내를 제공합니다. 정답률이나 소요 시간을 학습능력·집중력 측정값으로 해석하지 않습니다.

## 데이터와 기록

`data/discrete_math.json`은 10문항의 문제·정답·해설·피드백과 주제, 난이도, 답안 유형을 담습니다. ID 중복과 필수 필드, 답안 형식을 검사합니다. 다른 과목을 추가할 때는 해당 과목의 정답 검토와 채점 유형·주제 키워드 설정이 필요합니다.

실제 풀이 기록은 지정한 출력 폴더에 JSON과 한국어 HTML로 저장합니다. 고유 파일 이름을 사용해 기존 결과를 덮어쓰지 않으며, 사용자 답안은 HTML escape합니다. HTML은 브라우저에서 PDF로 인쇄할 수 있습니다. 기본 설정은 기록을 저장하지 않습니다.

TXT/MD는 UTF-8로 읽습니다. PDF는 검토된 PyPDF2 환경에서만 명시적으로 켤 수 있으며 암호화 PDF와 OCR은 지원하지 않습니다. 기본 자료 연결 기능은 키워드로 기존 문제은행의 주제를 찾습니다.

## GPT-2 실험

`ai_experiments.py`의 `load_local_gpt2`, `fine_tune`, `generate_draft`를 사용합니다. 검토된 패키지 환경과 로컬 GPT-2 가중치가 있어야 합니다. 노트북의 `RUN_AI_EXPERIMENT`와 `REVIEWED_AI_ENV`는 기본적으로 꺼져 있습니다.

학습에는 주제·난이도를 포함한 공통 프롬프트와 문제·정답·해설·피드백 JSON 응답을 사용합니다. 질문 단위로 시드를 고정해 학습/검증 데이터를 나누고 응답 토큰에만 손실을 계산합니다. 길이가 넘으면 정답을 자르지 않고 오류를 냅니다. 검증 손실과 학습 전 기준선을 비교하며, 손실이 나빠지면 더 나은 상태를 복구합니다. 비정상 손실이나 gradient는 오류로 보고합니다.

생성은 새 토큰만 디코딩하며 형식이 잘못되면 오류를 반환합니다. JSON 형식이 맞아도 내용의 정확성은 보장되지 않습니다. 결과에는 `needs_human_review`를 표시하고 기본 채점 대상에 넣지 않습니다. 자료 기반 생성 프롬프트는 있으나 현재 데이터에는 그에 맞는 학습 예제가 없어 성능을 확인하지 않았습니다.

10문항의 학습/검증 분할은 실행 흐름을 위한 실험이며 생성 정확도나 일반화 성능을 입증하지 않습니다.

## LSTM 실험

`fit_history_lstm`은 한 학습자의 실제 시간순 기록을 최소 40개 받아 과거 5회 기록에서 다음 정답 여부를 예측합니다. 입력은 문제 난이도·정답 여부·소요 시간으로 구성한 `(batch, sequence, 3)` 형태입니다. 연속값을 PyTorch LSTM에 직접 입력하고 이진 분류 출력을 사용합니다.

시간순 학습/검증 분할과 상수 예측 기준선의 Brier score 비교를 포함합니다. 기본 난이도 정책과 자동으로 연결하지 않습니다. 서로 다른 학습자나 합성 데모의 기록을 섞지 않아야 합니다. 최소 40개는 실행 조건일 뿐 충분한 데이터라는 뜻이 아니며 별도 테스트 집합과 학습자별 검증이 필요합니다.

## 외부 코드와 실행 환경

이 저장소의 기본 경로는 외부 통신, 패키지 설치 또는 모델 다운로드를 하지 않습니다. 선택 모델 경로는 로컬 디렉터리, `local_files_only=True`, `token=False`, safetensors 및 GPT-2 전용 클래스를 사용합니다. 선택적 PDF 경로는 사용자가 지정한 로컬 파일을 읽습니다.

패키지·전이 의존성·모델의 전체 소스, 바이너리, 라이선스, 공급망은 이번 검증 범위에 포함하지 않았습니다. 따라서 기본 코드만 실행 검증했으며 신경망 학습·생성과 PDF 라이브러리 실행은 확인하지 않았습니다.

외부 구성 요소를 도입할 때는 프로젝트와 자동 탐색 경로 밖의 별도 검토 폴더에 먼저 다운로드하고 출처, 고정 버전/커밋, 아카이브 해시를 기록합니다. 검사 전 설치·활성화·빌드·테스트·import·설정 스크립트 실행을 하지 않습니다. 진입점, 의존성, 통신, 자격증명과 파일 접근, 파괴적 동작, 권한, 난독화와 바이너리, 에이전트 지침 조작, 라이선스를 검토합니다. 중대한 위험이나 실행 경로 분석 공백이 있으면 사용을 보류합니다.

검토된 정확한 버전만 사용하고 자동 업데이트를 끕니다. 정적 검사만으로 완전한 안전을 보장할 수 없으며, 동적 검사가 필요하면 비밀정보 없는 실제 격리 환경에서 수행합니다. 실행 플래그를 바꾸거나 폴더를 분리하는 것만으로 검토와 격리를 대신할 수 없습니다.
